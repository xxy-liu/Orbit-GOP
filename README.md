# Orbit-GOP

Orbit-GOP: Near-Out-of-Distribution Detection for Evidential Deep Learning via Cross-View Functional Stability

Orbit-GOP is a prediction-preserving inference-stage calibration method for evidential deep learning, using cross-view functional stability to refine uncertainty ranking for near-OOD detection.

## Repository status

This repository accompanies the Orbit-GOP manuscript being prepared for submission.

The complete research code, extended experimental documentation, reproducibility materials, and archived result records corresponding to the manuscript will be released here after manuscript submission.

The current repository records the stable project location for the submission.
No claim of complete reproducibility is made for this initial repository state.
