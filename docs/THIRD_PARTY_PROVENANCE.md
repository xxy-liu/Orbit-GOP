# Third-party provenance and redistribution

No upstream project is claimed as Orbit-GOP. Only the components below are retained; original notices are in [licenses](../licenses). Original Orbit-GOP contributions follow the separate [project usage notice](../USAGE_NOTICE.md) and [policy status](PROJECT_LICENSE_STATUS.md). Earlier local Git-object checks associated the two MIT notices with recorded revisions; see [verification record](../provenance/UPSTREAM_LICENSE_VERIFICATION.json). Exact upstream fixed revisions have not been independently reverified remotely in this release pass.
