# Historical archive scope

Orbit-GOP's development involved additional analysis, figure preparation, and archived execution scripts. The public release does not distribute the `scripts/archive/**` source files. The publication release is scoped to the portable confirmatory implementation and selected evidence; provenance and redistribution rights for the historical archive were not closed file by file.

Historical numerical evidence remains reported within the paper's historical evidence scope (S0–S2). The exclusion of historical executors does not alter any frozen paper value. Selected historical result artefacts and provenance records remain, with their original status and limitations. This repository does not claim complete end-to-end rerun of all historical analyses or final figure layouts.

The S3–S5 confirmatory core implementation in `orbit_gop/`, `models/`, `baselines/`, `training/`, and `scripts/confirmatory/` remains included. The archive exclusion is recorded by metadata only in [`provenance/HISTORICAL_ARCHIVE_FILE_INDEX.csv`](../provenance/HISTORICAL_ARCHIVE_FILE_INDEX.csv); that index contains no excluded source content.
